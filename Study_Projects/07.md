# Project Title: The High-Availability Gateway & Traffic Controller

This project simulates configuring a Linux server as a resilient corporate gateway. You will combine multiple network connections for reliability, block unauthorized network traffic, redirect internal ports, and balance incoming loads across backend services.

## Phase 1: Network Redundancy & Link Aggregation

* Form Interface Bonds: Combine two physical network interface cards into a single logical bonding or teaming interface.
* Configure Failover Modes: Set up the bond mode (such as Active-Backup or Link Aggregation Control Protocol) to ensure zero downtime if a cable is pulled.
* Validate Redundancy: Simulate a hardware interface failure to verify that network traffic passes uninterrupted through the backup link.

## Phase 2: Firewall Enforcement & Traffic Filtering

* Establish Default Policies: Configure a stateful firewall (using nftables or firewalld) to block all incoming traffic by default while allowing outgoing requests.
* Open Targeted Services: Create explicit firewall rules to accept incoming traffic only on specific corporate ports (e.g., HTTP, HTTPS, and SSH).
* Block Malicious Sources: Implement real-time packet-filtering rules to drop traffic originating from specific unauthorized IP subnets.

## Phase 3: Port Redirection & NAT Gateway Setup

* Enable Packet Forwarding: Configure the Linux kernel to allow network packets to pass between different network interfaces.
* Implement Masquerading (NAT): Set up Network Address Translation to hide internal private network systems behind a single public gateway IP.
* Configure Port Forwarding: Build destination NAT rules to automatically redirect web traffic hitting your gateway's public port over to an internal backend server.

## Phase 4: Load Balancing & Time Synchronization

* Deploy Traffic Balancers: Configure a lightweight load balancer (like HAProxy) to distribute web traffic evenly across multiple backend nodes.
* Establish Network Bootstrapping: Configure Network Block Devices (NBD) to access storage pools over the network for stateless backend systems.
* Synchronize Infrastructure Time: Deploy NTP or Chrony clients on all nodes to sync system clocks down to the millisecond with a reliable central time source.
