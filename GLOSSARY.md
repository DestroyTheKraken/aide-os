# Glossary

| Term | Meaning |
|------|---------|
| **AIDE / AIDE_OS** | This project: a learning layer for Linux administration, with a Student seat and an author seat. Not a game console. |
| **Student** | The learner in the software. Progress and the welcome screen belong to this name. |
| **Edbuntu** | Planned education-oriented Ubuntu flavor. AIDE stays a layer on official Ubuntu until that exists. |
| **HickMedia** | A separate media-hub experiment. Not part of the Student path. |
| **SovereignAid** | First-generation tree. Historical only. |
| **Lab LAN** | Wired administration network. See [homelab](https://github.com/DestroyTheKraken/homelab). |
| **Home LAN** | Household Wi-Fi network, isolated from the lab at the edge. |

Older notes may mention retired host names or NAS paths. Ignore those; they are not current.
