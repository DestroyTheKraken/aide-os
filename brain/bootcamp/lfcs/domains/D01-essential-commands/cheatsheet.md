# D01 cheatsheet

| Task | Command |
|------|---------|
| Where am I | `pwd` |
| Who am I | `whoami` / `id` |
| List | `ls -la` |
| Manual | `man <cmd>` |
| File type | `file PATH` |
| Metadata | `stat PATH` |
| Bounded find | `find DIR -maxdepth N ...` |
| FHS help | `man 7 hier` |
