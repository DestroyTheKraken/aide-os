# Project Title: The Log Analytics & Report Engine

This project simulates a real-world system administrator task: parsing raw, messy system log files to extract critical security data and generating a compressed, human-readable health report.

---

## Phase 1: Data Gathering & Consolidation

* Target System Logs: Locate the active system log files (such as /var/log/auth.log or /var/log/secure) containing authentication events.
* Stream Redirection: Append multiple text streams into a single raw working file in your staging directory without overwriting data.
* Isolate Timeframes: Extract data chunks from specific date ranges using basic line filtering techniques.

## Phase 2: Security & Error Filtering

* Identify Failed Logins: Use keyword matching to extract every instance of a failed SSH login attempt or unauthorized sudo request.
* Match Variable Patterns: Deploy regular expressions to isolate dynamic data fields, such as extracting only valid IPv4 addresses from the error lines.
* Invert Matches: Filter out routine, successful system messages to isolate unexplained anomalies and critical system warnings.

## Phase 3: Text Transformation & Formatting

* Column Extraction: Strip out unnecessary timestamps and process IDs to isolate just the username and the offending IP address.
* Stream Editing: Replace specific text strings globally (e.g., changing uppercase service names to lowercase or masking sensitive user IDs).
* Summarize & Count: Sort the extracted data to count how many times each specific IP address attempted to breach the system.

## Phase 4: Report Generation & Archiving

* Structure Layout: Format the final metrics into a clean, tab-delimited text summary report.
* Compress Assets: Bundle the raw log fragments and the final summary report into a single compressed archive file.
* Verify Integrity: Confirm the archive contents without extracting them to ensure the file is uncorrupted and ready for storage.
