# How to start (Student)

The learning seat is a person named **Student**. Progress was reset to day 1.

1. If an old Day Start tab is still open, stop that server (the terminal where you ran `aide-day`, **Ctrl+C**).
2. Start again:

```bash
aide-day
```

3. You should see **Welcome, Student**. Click **Begin as Student**.
4. Read the lesson on the page. Open a terminal and do the work (optional: `multipass start grokaide-edu && multipass shell grokaide-edu`).
5. Click **Start today's block**, then **Mark day complete** when you are done.

`aide-review` is only a parts list for building the product. It is not class. Use it when you want to keep or drop leftover folders — not when you are studying.
