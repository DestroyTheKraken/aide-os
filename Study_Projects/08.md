# Project Title: The Autonomous System Administrator

This final project ties everything together. You will automate all the system tasks you have learned so far—such as backing up file structures, rotating logs, auditing user permissions, and monitoring network states—by writing resilient shell scripts and scheduling them to run completely hands-free.

---

## Phase 1: Shell Scripting Foundations & Safety

* Implement Interpreter Directives: Start scripts with the correct shebang line (#!/bin/bash) to ensure deterministic execution environments.
* Enforce Strict Failure Modes: Configure shell execution options (like set -e and set -u) to halt script execution instantly if an unbound variable or error occurs.
* Manage Scope with Variables: Use local and global environment variables to store configuration directories, timestamps, and target paths cleanly.

## Phase 2: Logic Flow & System Interrogation

* Build Conditional Checks: Use evaluation blocks (if/then/else) to verify system states, such as checking if a backup drive is mounted before executing a write task.
* Process Looping Mechanims: Construct loop sequences (for and while) to iterate over lists of user accounts, network assets, or system logs.
* Handle Stream Redirection: Capture command outputs directly into variables, or redirect standard errors away from user terminals and into specialized audit text files.

## Phase 3: Automated Maintenance & Remediation Tasks

* Automate Tarball Backups: Build a maintenance script that bundles up the directory structures from Project 1 and compresses them using timestamped file names.
* Develop Log Rotation Tools: Write a text manipulation routine that parses active network connections from Project 6 and archives older connections automatically.
* Construct Health Monitors: Design a script that queries the kernel states from Project 4 and fires off a targeted alert if the root storage partition exceeds 90% capacity.

## Phase 4: Hands-Free Scheduling & Daemon Control

* Configure Short-Term Tasks: Schedule a non-recurring configuration modification task using the at daemon to execute at a precise future moment.
* Enforce Chronic Automation: Author user and system-wide crontab files to execute your automated maintenance scripts at specific hourly, daily, or weekly intervals.
* Isolate Environment Execution: Ensure scheduled cron jobs execute flawlessly by declaring absolute system paths for all commands and resources inside your scripts.
