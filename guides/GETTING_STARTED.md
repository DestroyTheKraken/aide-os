# Getting started

You are **Student**. Class happens in the browser, not in a pile of folders.

```bash
aide-day
```

1. If you see the welcome screen, click **Begin as Student**.
2. Read the lesson on the page (Project 00 on day 1).
3. Do the work in a terminal. Optional VM: `multipass start grokaide-edu && multipass shell grokaide-edu`.
4. Start the time block, then **Mark day complete** when you are finished.
5. The next time you open `aide-day`, you continue where you left off.

That is the whole daily loop.

The older tablet-and-Docker instructions that used to live in this file are out of date. Do not follow them. If you are building the product rather than taking class, see [START.md](../START.md) and [AGENTS.md](../AGENTS.md).
