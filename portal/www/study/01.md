# Project Title: The Directory Structure Sandbox

This practical project builds your muscle memory for navigating the Linux terminal, structuring files, and managing links without risking any critical system configurations.

---

## Phase 1: Environment & Secure Access

* Generate SSH Keypairs: Create a secure cryptographic key pair on your local host machine.
* Configure Remote Connection: Access your practice Linux system securely using the terminal via SSH.
* Environment Verification: Confirm your active terminal session shell, current working directory, and user identity.

## Phase 2: Directory Architecture & Navigation

* Build Workspace Trees: Create a multi-tiered directory structure (e.g., projects/archive/2026/) using a single command.
* Relative vs Absolute Navigation: Move deep into the folder hierarchy and back to your user home using both path styles.
* Hidden Resource Creation: Generate hidden configuration folders and files to simulate real-world Linux environment setups.

## Phase 3: File Population & Lifecycle Management

* Generate Sample Files: Populate your directories with blank files, copied templates, and unique file naming schemes.
* Bulk Relocation: Move entire batches of specific file types to your archive folders while leaving others behind.
* Recursive Mirroring: Duplicate entire directory branches to create instant backups of your workspace tree.

## Phase 4: Link Implementation

* Create Symbolic Links: Establish soft links (shortcuts) from your home directory directly to deep project files.
* Implement Hard Links: Create a hard link to a data file to observe how it persists even if the source file is deleted.
* Broken Link Testing: Intentionally delete a target file to witness how symbolic links break while hard links retain data.
