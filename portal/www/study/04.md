## Project Title: The High-Availability Service & Resource Monitor

This project simulates managing a critical backend service. You will control application life cycles, optimize system resource allocation, adjust kernel parameters for performance, and handle runaway processes.

---

## Phase 1: Service Lifecycle Management

* Unit File Manipulation: Create a custom systemd service unit file to manage a background application stub.
* State Control: Practice starting, stopping, restarting, and reloading the service without disrupting the OS.
* Boot Integration: Enable the custom service to start automatically at system boot, and verify its dependency tree.

## Phase 2: Process Diagnostics & Priorities

* Live Monitoring: Track system metrics and identify resource-heavy applications using real-time utilities.
* Static Analysis: Capture snapshot listings of all active processes to trace parent-child relationships.
* Priority Adjustment: Launch a heavy process with a lower scheduling priority, and dynamically alter an active process's priority.

## Phase 3: Resource Constraints & Control

* Session Restrictions: Configure system-wide limits to restrict the maximum number of open files and processes a user can spawn.
* Process Termination: Safely terminate unresponsive applications using standard signals, moving from polite termination to absolute forced kills.

## Phase 4: Runtime Kernel Tuning

* Live Parameter Querying: Review active kernel network and memory parameters directly from the virtual memory filesystem.
* Dynamic Adjustment: Modify a runtime kernel parameter (like system responsiveness or file limits) on the fly.
* Persistent Hardening: Write changes to the system configuration files to ensure kernel tweaks survive a system reboot.
