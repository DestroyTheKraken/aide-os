## Phase 1: Tailnet Identity & Least-Privilege Foundation

* Inventory Tailnet Assets: Record each node's Tailscale IP and role before deployment.
* Provision Service Identity: Create `forgesvc` — system account, `/sbin/nologin` shell, member of the `docker` group only as needed.
* Delegate Sudo Narrowly: Install `/etc/sudoers.d/forgesvc` with command-literal restrictions validated by `visudo -c`.
* Map Container Ownership: Set `PUID`/`PGID` in Docker Compose to match `forgesvc` so volume files are not owned by root.

## Phase 2: Secure Remote Management Hardening

* SSH Drop-In Configuration: Deploy `/etc/ssh/sshd_config.d/99-lfcs-forge.conf` — `PermitRootLogin no`, key-only auth.
* Validate Before Reload: Always run `sshd -t` before `systemctl reload sshd` (LFCS exam trap: lock yourself out).
* Audit Auth Logs: Practice extracting failed SSH attempts from `/var/log/secure` (Project 02 skill).

## Phase 3: Containerized Service Platform (Docker Compose)

* Install Docker Engine: Use `dnf install docker-ce` (or `moby-engine`) on Rocky Linux; enable `docker.service`.
* Deploy Mullvad Browser: Run `secure-browser-forge.sh` to pull `linuxserver/mullvad-browser` and start the stack.
* Bind to Tailscale Only: Compose publishes port `3001` on the Tailscale IP — never `0.0.0.0`.
* Enable Restart Policy: `restart: unless-stopped` plus a systemd unit wrapping `docker compose up -d` for boot persistence.

## Phase 4: Tailnet-Only Network Perimeter

* firewalld Rich Rules: Allow TCP `3001` only from `100.64.0.0/10` on interface `tailscale0`.
* Drop Public Exposure: Confirm `ss -tlnp` shows the Tailscale IP, not all interfaces.
* Cross-Node Test: Open `https://<tailscale-ip>:3001/` from Node1; verify LAN-side access is blocked.

## Phase 5: Automation, Validation & Persistence Proof

* Run Interactive Deploy Script: `sudo ./automation/secure-browser-forge.sh` — menu-driven, idempotent, safe to re-run.
* Generate Validation Evidence: Script auto-writes `validation/VALIDATION.md` with timestamped command output.
* Reboot Survivability: `sudo reboot` → reconnect via Termius → re-run validation menu option → all checks pass.
