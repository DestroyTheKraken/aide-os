# L01 — What is the shell?

> [!summary] TL;DR
> The shell is a text program that runs commands. Your prompt is waiting for input.

> [!todo] Next
> - [ ] Run the three commands below and write what each prints

## Concept

Linux admin work is mostly: **tell the system to do something**, then **read the result**. The shell is the conversational interface for that.

## Why ops care

Scripts, SSH sessions, and exam tasks are all shell-first.

## Try it (read-only)

```bash
whoami
pwd
echo "hello from $SHELL"
```

## Common mistakes

- Typing a command in the wrong directory
- Assuming GUI actions are what the exam tests (LFCS is CLI)

## Official

- `man bash` (or your shell’s man page)
- `man 1 intro` if available
