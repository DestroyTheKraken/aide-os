# Project Title: The Connected Client Node Setup

This project simulates onboarding a new Linux node into a corporate network. You will configure persistent network settings, set up local and remote name resolution, configure secure remote management access, and mount shared storage over the network.

---

## Phase 1: Network Interface Configuration

* Identify Network Assets: Locate active network interface cards and view their current operational status and link speeds.
* Assign Static Addressing: Configure persistent IPv4 and IPv6 static addresses, subnets, and default gateways on a target interface.
* Verify Interface Connectivity: Test point-to-point network pathways using basic ICMP probing tools to ensure physical and logical link success.

## Phase 2: Name Resolution & DNS Setup

* Configure Static Lookups: Edit local host files to map internal server names directly to IP addresses for zero-latency lookups.
* Implement External DNS: Configure system-wide nameserver settings to resolve public internet domains through external DNS servers.
* Trace Resolution Pathways: Test and trace the resolution path of a domain name to confirm correct lookups and isolate resolution failures.

## Phase 3: Secure Remote Management (SSH)

* Harden Daemon Configurations: Modify the secure shell (SSH) server configuration to change the default port and disable direct root log-ins.
* Deploy Key-Based Authentication: Enforce mandatory SSH public key authentication while turning off weak password-based access.
* Manage Active SSH Sessions: Monitor active remote user connections and clean up stale or unauthorized terminal sessions safely.

## Phase 4: Network Storage Integration

* Discover Remote Shares: Scan a target network storage server to locate available Network File System (NFS) exports.
* Mount Network Storage: Attach NFS shares and secure SSH filesystems (SSHFS) into your local file structure.
* Automate Network Mounts: Add the remote storage configurations to the system boot table, ensuring they mount automatically only after the network link comes online.
