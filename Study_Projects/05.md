# Project Title: The Enterprise Storage Provisioning Lab

This project simulates adding a new hard drive to a production server. You will partition the physical disk, implement elastic storage scaling, format reliable filesystems, and configure permanent, fail-safe mounts.

---

## Phase 1: Physical Disk Partitioning & Layout

* Identify New Hardware: Locate newly attached unformatted storage disks using system block device utilities.
* Construct Partition Schemas: Create modern GPT partition tables on raw disks using command-line partitioning tools.
* Initialize Swap Spaces: Allocate and format a dedicated partition for virtual memory swap space to support low-RAM scenarios.

## Phase 2: Filesystem Creation & Optimization

* Format Block Devices: Deploy robust Linux filesystems (such as Ext4 and XFS) onto your fresh partitions.
* Label Storage Volumes: Assign unique hardware UUIDs and human-readable volume labels to the newly formatted filesystems.
* Activate Virtual Memory: Enable the freshly prepared swap space and verify that the system recognizes the expanded memory pool.

## Phase 3: Persistent Mount Integration

* Establish Target Mountpoints: Create standard directory structures within the system root to host the new storage volumes.
* Configure Fail-Safe Mounting: Edit the permanent filesystem table (/etc/fstab) using device UUIDs to prevent boot failures if drive order changes.
* Validate Mount Configurations: Test the integrity of your mounting configurations safely without rebooting the system to catch syntax errors.

## Phase 4: Storage Performance & Maintenance

* Monitor Disk Consumption: Track live storage usage, remaining capacity, and inode exhaustion across all mounted filesystems.
* Assess Storage Performance: Run basic input/output benchmarks to measure read and write efficiency on your storage layout.
* Execute Filesystem Checks: Perform safe manual filesystem diagnostics on unmounted blocks to detect and repair metadata corruption.
